# Recueil de chants

Appli web (un seul fichier `index.html`) pour consulter les chants traditionnels protestants de Nouvelle-Calédonie : recueils (Tapéras, Cantiques ajië, Chants de prières…), recherche par numéro ou par titre, rubriques, mélodies et import d'un recueil PDF.

Les chants sont enregistrés dans le navigateur de chaque appareil (sauvegarde / restauration en fichier JSON).

Déploiement : Netlify, publication automatique depuis la branche `main`.
